📧 SISTEMA DE EMAILS (ELIGE UNO):

OPCIÓN A: FORMSPREE (RECOMENDADO - MÁS FÁCIL)
  1. Ve a https://formspree.io
  2. Crea una cuenta gratis
  3. Obtén tu form_id
  4. Abre script.js línea ~96
  5. Cambia: const formspreeId = 'your_formspree_id';
  6. Por: const formspreeId = 'xyzabc123'; (tu ID)
  7. ¡LISTO!

OPCIÓN B: EMAILJS (MÁS CONTROL)
  1. Ve a https://www.emailjs.com
  2. Crea una cuenta gratis
  3. Obtén Service ID, Template ID, Public Key
  4. Abre script.js líneas 10-15
  5. Reemplaza los 3 valores
  6. ¡LISTO!

🆘 SOLUCIÓN DE PROBLEMAS:

❌ EL FORMULARIO NO ENVÍA EMAILS
  → Verifica haber configurado Formspree o EmailJS
  → Abre la consola (F12) para ver errores
  → Asegúrate que tu navegador tiene internet
  → Prueba en otro navegador

❌ LA FOTO NO SE CARGA
  → Verifica que la URL sea válida
  → Comprueba que el archivo exista
  → Prueba haciendo click en la foto
  → Intenta con una URL de ejemplo

❌ LOS ESTILOS SE VEN MAL
  → Asegúrate que styles.css esté en la misma carpeta
  → Limpia el caché: Ctrl+Shift+Del
  → Recarga la página: Ctrl+F5
  → Prueba en otro navegador

❌ EL MENÚ NO FUNCIONA EN MÓVIL
  → Limpia el caché del navegador
  → Cierra y abre el navegador nuevamente
  → Prueba en otro navegador móvil
  → Usa modo incógnito

❌ EL SCROLL NO FUNCIONA SUAVE
  → Algunos navegadores antiguos no soportan scroll suave
  → Prueba en un navegador moderno
  → Verifica script.js esté cargado correctamente
