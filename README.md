## 🎨 Personalización

### Cambiar Contenido
1. Abre `index.html`
2. Busca el texto que quieres cambiar
3. Reemplaza con tu información
4. Guarda el archivo

### Cambiar Colores
1. Abre `styles.css`
2. Busca la sección `:root` (líneas 4-14)
3. Cambia los códigos hexadecimales
4. Guarda el archivo

### Cambiar Foto de Perfil
- **Opción 1:** Haz clic en la foto en el navegador
- **Opción 2:** Edita el `src` en `index.html` línea 58

## 🆘 ¿Problemas?

### El formulario no envía emails
→ Verifica que configuraste EmailJS o Formspree correctamente

### La foto no se carga
→ Comprueba que la URL sea válida y accesible

### Los estilos no se ven bien
→ Asegúrate que `styles.css` esté en la misma carpeta

### El menú no funciona en móvil
→ Limpia el caché del navegador

👉 **Consulta GUIA_CONFIGURACION.md para soluciones detalladas**
